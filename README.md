# Le Kiosque

Revue de presse générée chaque matin : unes du Figaro, du Monde, de La Croix et de L'Équipe, puis sélections Monde, IA et Juridique.

- Collecte et publication : `.github/workflows/edition.yml` (GitHub Actions → GitHub Pages)
- Sources : `scripts/config.py`
- Résumés rédigés par une routine Claude : voir `ROUTINE.md`
- Test local : `python3 scripts/build.py` puis ouvrir `site/index.html`
